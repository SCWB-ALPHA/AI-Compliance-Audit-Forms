🛡️ AI Compliance Audit Forms

A lightweight, web-based tool to evaluate and document AI compliance across governance areas.

AI Compliance Audit Forms provides a structured way to review and capture compliance across laws, ethics, security, oversight, consent, accessibility, and more—using guided measures and example checks.

📌 Features

Audit Categories

  • Jurisdiction-Specific Laws
  • Universal Ethics
  • Cross-Border Transfers
  • Security Measures
  • Consent & Transparency
  • Third-Party Audits
  • AI Oversight
  • Incident Management
  • Accessibility

Compliance Measures

  • Encryption at rest/transit, access control, patching
  • Bias detection and mitigation
  • Documentation and ongoing assessment

Example Checks

  • Is encryption used for all sensitive data?
  • Are audit certificates up to date?
  • Does the AI support screen reader technologies?

🏗️ Project Structure

The project uses Tailwind CSS for styling and vanilla JavaScript for interactivity.

ai-compliance-audit-forms/
│
├── index.html        # Main app file (UI + logic)
├── README.md         # Documentation
└── assets/           # (Optional) Future CSS/JS/Images

⚙️ Tech Stack

  • Frontend: HTML5, Tailwind CSS, JavaScript (Vanilla)
  • Fonts: Inter
  • UI/UX: Responsive design, accessible controls, audit-item cards

🚀 How to Run

  1. Clone the repository: 
    git clone https://github.com/your-username/ai-compliance-audit-forms.git
cd ai-compliance-audit-forms
  2. Open index.html in your browser.

💡 No build tools required. Everything runs client-side.

📂 Audit Categories Overview

🏛️ Laws

  • Measures: EU AI Act, GDPR, HIPAA, PIPL compliance
  • Checks: Legal disclosures, consent forms

⚖️ Ethics

  • Measures: Fairness, transparency, accountability
  • Checks: Model cards, human reviewability

🌍 Transfers

  • Measures: SCCs, BCRs, adequacy rules
  • Checks: Validity of transfer mechanisms

🔐 Security

  • Measures: Encryption, patching, access control
  • Checks: Logs, suspicious activity audits

📝 Consent

  • Measures: Informed consent, data access rights
  • Checks: Consent dashboard, request handling

🔎 Third-Party Audits

  • Measures: External audit certificates
  • Checks: Certificate availability & validity

👁️ Oversight

  • Measures: Explainability, redress mechanisms
  • Checks: Human review of AI decisions

🚨 Incident Management

  • Measures: Breach logs, forensic reporting
  • Checks: Incident reporting timelines

♿ Accessibility

  • Measures: WCAG compliance, multiple inputs
  • Checks: Screen reader support, inclusive training data
